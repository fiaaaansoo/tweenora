## Scope

The public API is everything that the `rive.d.ts` of the `@tweenora/webgl2` package (`typings` field) declares, re-exports or makes reachable: (1) the exported classes, interfaces, enumerations, types, functions and constants; (2) the non-exported declarations of `rive.d.ts` (`BindableArtboard`, `EventManager`...) and the types imported from the neighboring modules `./utils`, `./semantics` and `./runtimeLoader` (`ImageWrapper`, `AccessibilityOverlay`...), which public signatures return or accept; they carry the mention "not exported"; (3) for each, its public members (methods, properties, accessors, constructor, static members, enumeration values; overloads of the same name form one line), and the values of constants of object literal type (`DeprecationKeys`, `Testing`). Private and protected members are excluded; an inherited member is listed once, on the class that declares it. Excluded: the rest of `rive_advanced.mjs.d.ts`, the low-level API of the WASM module (`RiveCanvas`, renderers, paths) that `rive.d.ts` only exposes through types; `FileAsset`, `AudioAsset`, `FontAsset` and `ImageAsset`, re-exported by `rive.d.ts`, are however listed; the default export, which designates an already listed class; the contents of the literal types of a `type` alias. The `internal*`, `selfUnref` or `handleCallbacks` members are public in the `.d.ts`: a `not demonstrated` line with the reason "internal member" is allowed.
