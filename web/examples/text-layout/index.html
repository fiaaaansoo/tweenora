Text and layout

Prepare the assets with python web/examples/prepare_assets.py; each page accepts a .twno or a .riv in ?file=.

  • text.html: text runs (new_text: "Text Run"), text runs nested by path (runtime_nested_text_runs), hosted font (hosted_font_file with &hosted=/assets/OpenSans-Italic.ttf), fallback fonts (fallback_fonts_test with &autobind=1).
  • responsive.html: Fit.Layout and three canvas sizes (mobile, tablet, desktop), scale factor, pixel ratio (layout_aspect_ratio, layout_text_match, layoutstest_8-planets-grid, grid_2x2 with &stateMachine=Auto%20Generated%20State%20Machine, layout_scroll_vertical).
