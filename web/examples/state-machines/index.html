Animations and state machines

Prepare the assets with python web/examples/prepare_assets.py; each page accepts a .twno or a .riv in ?file=.

  • playback.html: play, pause, stop, scrub, reset, events Play, Pause, Stop, Loop, Advance, StateChange; parameters &stateMachine=, &animations=, &artboard=.
  • inputs.html: boolean (click_event), number (sound) and trigger (state_machine_triggers) inputs, emitted state names.
  • events.html: EventType.RiveEvent; nested_events with &autobind=1&size=200.
  • pointer.html: mouse to listeners, setupRiveListeners, removeRiveListeners, &listeners=off.
