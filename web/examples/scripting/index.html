Files with scripts (Luau)

Prepare the assets with python web/examples/prepare_assets.py; the page accepts a .twno or a .riv in ?file=. Script inputs are view model properties.

  • script_inputs_test_1: a script draws a polygon; twnoCheck.set("color","Color",0xffff0000) then twnoCheck.trigger("Trigger").
  • scripting_linear_animation: twnoCheck.set("string","mode","rot") then twnoCheck.set("number","time",0.5).
  • viewmodel_access: the script reads the view model and displays its values.
  • audio_script: seven triggers (twnoCheck.trigger("play")...), the sound is checked by ear.
