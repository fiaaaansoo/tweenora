# Provenance of the example files

Files copied by `web/examples/prepare_assets.py` for the examples and the demo. The copies are not versioned in
this repository (the `assets/` folder is ignored). The first four rows are the original Tweenora examples,
generated by `tools/twno_gen/` and versioned in `docs/examples/`; the others come from the upstream test folders
(`rive-runtime` at commit `daf55385`, `rive-wasm` at commit `589b787c`).

Rule: only a file whose license is established by written proof in this table is "publishable". The upstream MIT
license (`runtime/LICENSE`, `web/rive-wasm/LICENSE`) covers their code; nothing in the repository says it covers
their resources. "to verify" counts as "no" until proof is added.

Publishable fonts: the five fonts below carry the OFL 1.1 license in their `name` table; publishing one requires
shipping the OFL license text and the listed copyrights, which `THIRD_PARTY_NOTICES` does not yet do for them: add
them if a font is put online.

The original Tweenora examples (`docs/examples/`) are written in code, without an editor: their proof is the generation script and the byte-identical regeneration test. Those that would need the editor wait until it exists.
