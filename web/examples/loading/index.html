Loading and playback

Prepare the assets with python web/examples/prepare_assets.py; each page accepts a .twno or a .riv in ?file=.

  • url.html: loading from a URL (src).
  • zero-size.html: resizeDrawingSurfaceToCanvas() in the onLoad of a second Rive on a zero-size canvas (&visible=1 to make it visible).
  • buffer.html: loading from an ArrayBuffer, directly or through a RiveFile (&host=file).
  • shared-file.html: a RiveFile shared by two instances, then released.
  • named.html: named artboard and state machine (&artboard=, &stateMachine=), file contents.
  • layout.html: Layout, Fit, Alignment and canvas size at run time.
  • reload.html: load() with src, buffer and riveFile.
  • runtime-loader.html: RuntimeLoader, non-SIMD fallback (?wasm=/pkg/absent.wasm) and errors (?file=/assets/absent.twno).
  • self-hosted.html: no configuration, no request outside the served domain (P3-4).
  • asset-loader.html: image hosted outside the file, provided by assetLoader.
  • diagnostics.html: FPS counter, stopping and resuming rendering, drawing options.
  • accessibility.html: semantics, keyboard focus.
