Audio

Prepare the assets with python web/examples/prepare_assets.py; the page accepts a .twno or a .riv in ?file=. The browser only allows sound after a user gesture.

  • audio.html: embedded audio driven by a number (sound), volume, AudioContext state.
  • sound2, nested artboard (child, parent, grand-parent, no-audio).
  • hosted audio: assetLoader with what.wav (&hosted=).
