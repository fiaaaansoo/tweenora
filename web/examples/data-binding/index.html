Data binding and view models

Prepare the assets with python web/examples/prepare_assets.py; each page accepts a .twno or a .riv in ?file=. Binding only applies while a state machine plays (&stateMachine=, "State Machine 1" by default).

  • values.html: String, Number, Boolean, Trigger, Color, Enum, observation with on and off (data_binding_test, custom_property_enum, data_binding_test_triggers).
  • lists.html: lists (list_items).
  • assets.html: bound images, fonts and artboards (data_binding_images_test, data_bind_font_test, data_binding_artboards_test).
  • viewmodels.html: view models, instances, DataEnum, binding, global view models (global_viewmodels_test), nested properties (data_binding_images_test).
